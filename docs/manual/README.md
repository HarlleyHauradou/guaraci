# Manual do Guaraci

O manual tem dois volumes, escritos junto com o código:

| Volume | Para quem | Conteúdo |
|---|---|---|
| [I — Manual do Usuário](usuario/README.md) | quem monta e roda simulações | instalação, linguagem `.gci`, seções, materiais, fontes, probes, comandos |
| [II — Manual Técnico](tecnico/README.md) | quem quer saber *como* o Guaraci calcula | arquitetura, unidades, dados nucleares, materiais, física, validação |

Partes marcadas com **(em desenvolvimento)** descrevem o que já é aceito no
arquivo de entrada mas ainda não é calculado.
