# A filosofia do Guaraci

1. A entrada é escrita para humanos; a máquina que se esforce.
2. Legível vence esperto.
3. Erros devem ensinar.
4. Simples na superfície, rigoroso por dentro.
5. O usuário pensa em órgãos e atividades, não em superfícies e cartões.
6. Dois físicos lendo o mesmo arquivo devem imaginar o mesmo experimento.
7. Na dúvida, o código pergunta; nunca adivinha.
8. O arquivo de entrada é o caderno de laboratório da simulação.
9. A saída deve ser tão clara quanto a entrada; números sem explicação são só um amontoado de dados.
10. Escrever pode exigir o manual; ler, não.
11. Dez linhas claras valem mais que uma linha mágica.

# The Guaraci philosophy

1. Input is written for humans; let the machine do the work.
2. Readable beats clever.
3. Errors should teach.
4. Simple on the surface, rigorous underneath.
5. Users think in organs and activities, not in surfaces and cards.
6. Two physicists reading the same file should picture the same experiment.
7. When in doubt, the code asks; it never guesses.
8. The input file is the simulation's lab notebook.
9. Output should be as clear as the input; numbers without explanation are just a pile of data.
10. Writing may need the manual; reading should not.
11. Ten clear lines are worth more than one magic line.
